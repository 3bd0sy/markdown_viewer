# ⌨️ Keyboard Shortcuts

Complete reference for all keyboard shortcuts.

[← Back to README](../README.md)

---

## Formatting

| Shortcut               | Action        |
| ---------------------- | ------------- |
| `Ctrl` + `B`           | **Bold**      |
| `Ctrl` + `I`           | _Italic_      |
| `Ctrl` + `K`           | Insert link   |
| `Ctrl` + `` ` ``       | Inline code   |
| `Ctrl` + `Shift` + `K` | Code block    |
| `Ctrl` + `Shift` + `M` | Mermaid block |

---

## Editing

| Shortcut               | Action            |
| ---------------------- | ----------------- |
| `Ctrl` + `Z`           | Undo              |
| `Ctrl` + `Shift` + `Z` | Redo              |
| `Ctrl` + `A`           | Select all        |
| `Ctrl` + `F`           | Find (browser)    |
| `Tab`                  | Indent            |
| `Shift` + `Tab`        | Outdent           |
| `Ctrl` + `Enter`       | Insert line break |

---

## Saving

| Shortcut     | Action                 |
| ------------ | ---------------------- |
| `Ctrl` + `S` | Save to `localStorage` |

---

## View

| Shortcut               | Action                  |
| ---------------------- | ----------------------- |
| `Ctrl` + `Shift` + `Z` | Toggle Zen mode         |
| `Ctrl` + `Shift` + `D` | Toggle dark/light theme |
| `Ctrl` + `Shift` + `L` | Switch language         |

---

## Diagram Viewer

When a diagram is in fullscreen:

| Shortcut    | Action      |
| ----------- | ----------- |
| Mouse wheel | Zoom in/out |
| Drag        | Pan         |
| `0`         | Fit to view |
| `+` / `-`   | Zoom in/out |
| `Esc`       | Close       |
| `S`         | Save as PNG |
| `V`         | Save as SVG |

---

## Tab Navigation

When a **Tabs** block is focused:

| Shortcut | Action       |
| -------- | ------------ |
| `←`      | Previous tab |
| `→`      | Next tab     |
| `Home`   | First tab    |
| `End`    | Last tab     |

---

## Markdown Editing Tips

| Input         | Result          |
| ------------- | --------------- |
| `**text**`    | **bold**        |
| `*text*`      | _italic_        |
| `` `code` ``  | `code`          |
| `# Heading`   | Heading 1       |
| `## Heading`  | Heading 2       |
| `- item`      | Bullet list     |
| `1. item`     | Numbered list   |
| `- [ ] task`  | Task list       |
| `> quote`     | Blockquote      |
| `---`         | Horizontal rule |
| `[link](url)` | Hyperlink       |
| `![alt](url)` | Image           |
